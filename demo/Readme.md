## Important File Overview

- ### pages
    - **0⚡Quick Overview.py**: Streamlit app that contains a quick overview of initial work in the project.
    - **1🏭 Production EDA.py**: Streamlit app that contains exploratory data analysis of production.
    - **2📊 Sales EDA.py**: Streamlit app that contains exploratory data analysis of sales.
    - **3🔮Future Ideas.py**: Streamlit app that provides initial future ideas for project direction.
    - **4📊Results.py**: Streamlit app of midterm progress of the project.
    - **coates_app.py**: Streamlit app of final progress that highlights FCPS overall and focuses on Coates Elementary for specific school metrics.
    - **streamlit_app.py**: Streamlit app of final progress that highlights FCPS overall and all of the schools in the county.
